# 自制 App，自由用

**不付开发者年费，也能让自己写的多个 App，在自己的 iPhone 和 iPad 上持续使用。**

我买了设备，也会写软件。给自己做一个工具，给孩子做几个游戏，再装到家里的手机和平板上——这本该是一件简单的事。

但免费开发签名让这件事变得很琐碎：安装数量有限，签名七天到期，多一台设备就多一份维护。App 越写越多，反而开始犹豫：还装得下吗？过几天还能打开吗？又要接电脑重新签吗？

这个 skill 就是为了解决这样的困扰：**让你继续开发想做的 App，把安装和续签整理成一套尽可能省心的日常流程。**

## 想做几个 App，就继续做

一个遥控器、一个口算工具、几个小游戏，不必为了每个小想法都腾出一个独立签名的安装名额。

这套方案通过 LiveContainer 运行多个兼容的自制 App。容器内的 App 不需要各自占用一个原生安装名额，也不用各自向 Apple 注册 App ID。你可以继续添加自己的作品，不必一到第四个 App 就停下来。

## 手机、平板，都用上自己的作品

同一套 App 可以分别接入自己的 iPhone 和 iPad。Agent 负责识别设备、处理安装、备份与迁移记录，并为每台设备生成对应的启动捷径。

换设备时沿用已经跑通的方法；增加 App 时接入现有环境，不从头折腾。符合条件时，同一 Apple 账号下已经注册的 App ID 也可以跨设备重用。

## 续签，收敛成一个简单动作

首次设置完成后，让 Mac 运行 AltServer，设备与 Mac 连接同一个家庭 Wi-Fi。在每台设备的 AltStore 里点 **Refresh All**，刷新 AltStore 和 LiveContainer 即可。

**容器里的多个 App，不需要逐个重新打包、安装和续签。** 正常刷新也不需要重新导入 App、搬存档或重建桌面入口。

免费签名的七天期限仍然存在。这套方案的目标，是把它变成容易完成的例行动作，而不是让你时刻惦记每一个 App 的到期日。建议每隔 3～5 天刷新一次；每台设备需要分别刷新。

## 把第一次的麻烦，交给 Agent

安装和续签涉及的工具是 **AltStore Classic + AltServer + LiveContainer**。你不必先学会它们的全部细节，可以直接对 Agent 说：

> 使用 `$ios-home-sideload`，帮我把多个自制 App 装到自己的 iPhone 和 iPad 上。我不想支付开发者年费，希望保留数据，并把以后续签的操作尽量简化。

Agent 会处理安装包、核对签名、保留必要扩展、备份记录、配置无线连接，并验证真正的拔线刷新。遇到下载超时、App ID 额度或启动问题，也有已经实践过的排查路径。

Apple 登录、设备信任和必要的系统确认，仍由你在自己的设备上完成。账号和凭证留在你自己的环境里，不需要购买第三方签名服务，也不需要在手机上额外安装 VPN。

## 使用它需要什么

- 自己的 iPhone / iPad，以及要安装的兼容 App。
- 一台 Mac，用于首次设置，并在刷新时运行 AltServer。
- 一个免费 Apple 账号，以及设备与 Mac 可互相访问的网络；续签时需要连接 Apple 服务。

已有 iPhone、iPad 的实际接入经验，覆盖多 App 导入、旧记录迁移、无线刷新与官方直启捷径。具体执行方法从 [SKILL.md](SKILL.md) 开始。

## 仍然需要知道的边界

它不会取消 Apple 的免费签名期限，也不保证所有 App 都兼容容器。单个容器切换 App 时，可能需要结束正在运行的应用。

官方直启捷径可以省去 Safari 入口；原 App 图标和“添加到主屏幕”仍需要一次手动选择。跨设备数据同步则取决于 App 自身，不会因为装进容器就自动出现。

**希望自己的苹果设备，更多地按自己的想法工作。写自己需要的软件，放到自己拥有的设备上，让使用作品比维护签名更值得花时间。**
